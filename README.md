# BlackBoxOS

A lightweight, 64-bit operating system built from scratch using C and Rust.

## Goals

- Minimal storage and memory usage
- Low CPU overhead
- Fast application startup
- Process and memory management
- Filesystem and device support
- Native applications
- Progressive Linux and Windows application compatibility

## Development

BlackBoxOS is under active development.

The initial goal is to create a bootable x86-64 kernel and test it in QEMU.

## Technology Stack

- C
- Rust
- NASM
- GNU Make
- QEMU
- Git
